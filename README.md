# 社会学学习课程

一套自学社会学的课程材料。目标不是背人名与体系，而是**建立可反复调用的社会学工具**——拿到一个经验现象，能说出它落在哪个传统里、能用哪些概念去问它。

## 怎么用

**直接用浏览器打开 `index.html`** 即可浏览全部课程。

## 课程结构

按三段组织：

| 段 | 课次 | 内容 |
|---|---|---|
| **第一段 · 骨架与史** | 1—9 | 社会学想象力 · 一条主线 · 理论是网 · 古典六人组 · 孔德与斯宾塞 · 涂尔干 · 三类视角 · 韦伯 · 齐美尔 · 滕尼斯 |
| **第二段 · 古典收尾与帕森斯** | 10—16 | 埃利亚斯 · 空白的二十年 · **帕森斯四课** · 默顿 |
| **第三段（进行中）** | 17 起 | 冲突理论 → 诠释取向 → 哈贝马斯 → 卢曼 → 吉登斯 → 布迪厄 → 当代格局 |

## 教学约定

- **每课固定七段**：思想背景 → 他面临什么问题 → 他提出什么回答 → 优点何在 → 缺点怎么暴露 → 被谁挑战 → 现代影响
- **每人一个把手词**（1 主 + 2 辅）——「清单」记不住，「把手」记得住
- **每课必有「自己动手转译」**——把理论用到自己的研究问题上
- **「挑战」的判据**：**动结论 ＝ 同范式内分歧；动前提 ＝ 真挑战**
- **引用须可核验**，落到具体书的具体行号
